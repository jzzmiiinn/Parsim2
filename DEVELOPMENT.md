# Development Guide

## Setup

Use the project’s pnpm workspace and lockfile:

```bash
pnpm install
pnpm start
```

The local Vite server runs on port `3000`.

## Checks

Run the checks before handing off changes:

```bash
pnpm run lint
pnpm exec tsc --noEmit
pnpm run build
```

Use `pnpm run serve` to preview the generated `build/` output.

## Adding a Parsim view

1. Add the page under `src/views/parsim/`.
2. Register its lazy-loaded component and path in `src/routes.ts`.
3. If it belongs in the sidebar, add a `NavItem` in `src/_nav.tsx` pointing to that route.
4. Reuse shared layout and CoreUI components; keep product-specific styles in `src/scss/style.scss`.

`AppContent` and `AppBreadcrumb` both read `src/routes.ts`. Keep route names and paths consistent there. The application uses hash URLs.

## Theme and sidebar state

Use CoreUI’s color-mode API for theme changes and preserve its local-storage behavior. Redux is reserved for sidebar visibility and collapse state.

## Source versus generated files

Make changes under `src/`, `public/`, or project configuration files. `build/` is generated by `pnpm run build`; do not edit its output directly.
